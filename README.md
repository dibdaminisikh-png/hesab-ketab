# حساب کتاب — دفترِ میرزا

یک دفتر حساب فارسی و بازی‌گونه برای تقسیم هزینهٔ دورهمی‌ها؛ طراحی با اولویت موبایل، فونت وزیر و تصویرسازی اختصاصی ایران قدیم.

## استفاده

۱. اسم میرزا و سفره‌دار را وارد کنید.
۲. ۲ تا ۱۲ ریزه‌خوار اضافه کنید. اسم میرزا از قبل بالای فهرست دیده می‌شود؛ با خاموش‌کردن «میرزا هم شریک هزینه‌هاست» فقط حساب‌نویس خواهد بود.
۳. فاکتورها، آیتم‌ها و مبلغ تومان را بنویسید و شریک‌های هر فاکتور، از جمله میرزا، را از فهرست بالای همان فاکتور انتخاب کنید.
۴. حساب را محاسبه و تصویر PNG رسید را دانلود کنید.

کنار هر فاکتور «اسکنش کن با AI!» قرار دارد. پس از انتخاب عکس و خواندن آن، نام و **مبلغ کل هر ردیف** در پیش‌نمایش قابل اصلاح‌اند؛ با تأیید، همان ردیف‌ها به فرم فاکتور افزوده می‌شوند. اسکن برای فعال‌شدن به Worker رایگان در حساب کلودفلر شما نیاز دارد؛ [راهنمای فعال‌سازی](docs/SCAN-SETUP.md).

سفره‌دار فقط دریافت‌کننده است. سهم هر آیتم مساوی تقسیم می‌شود؛ تومان‌های باقی‌مانده به ترتیب ثابت میرزا و سپس افراد توزیع می‌شوند تا جمع سهم‌ها دقیقاً برابر کل هزینه باشد. حساب فقط در مرورگر همان دستگاه ذخیره می‌شود؛ اطلاعات افراد به سرور یا GitHub ارسال نمی‌شود. فقط هنگام انتخاب اسکن، عکس فاکتور برای استخراج به کلودفلر ارسال می‌شود؛ برنامه عکس را ذخیره نمی‌کند.

## توسعه

در اولین بازدید با گوشی، راهنمای افزودن به صفحهٔ اصلی متناسب با آیفون یا اندروید نمایش داده می‌شود. بعد از بستن، از پایین دفتر دوباره قابل باز کردن است؛ هنگام اجرا از آیکون نصب‌شده نمایش داده نمی‌شود. فایل manifest و آیکون‌ها برای اجرای مستقل روی گوشی آماده‌اند؛ اجرای آفلاین هنوز اضافه نشده است.

Node.js 22.12 یا جدیدتر (برای Node 20 حداقل 20.19):

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

آدرس توسعه: `http://127.0.0.1:5173/hesab-ketab/`

## انتشار روی GitHub Pages

در Settings → Pages، گزینهٔ Source را GitHub Actions قرار دهید. گردش‌کار `.github/workflows/deploy.yml` با هر push روی `main` آزمون‌ها را اجرا و خروجی `dist` را منتشر می‌کند؛ pull request فقط تست و build می‌شود.

آدرس: https://dibdaminisikh-png.github.io/hesab-ketab/

برای تغییر نام مخزن، مسیر `base` در `vite.config.ts`، مسیرهای `/hesab-ketab/` در `src/styles.css`، manifest و این راهنما را هماهنگ کنید. ورود دستی به backend نیاز ندارد؛ اسکن از Worker با AI binding و Turnstile استفاده می‌کند و کلید محرمانه‌ای در فرانت‌اند ندارد.

## تصاویر و فونت

- تصویرسازی‌ها با ابزار داخلی ImageGen ساخته شده‌اند؛ سه درخواست اصلی: حیاط ایران قدیم، پنج شخصیت شفاف و دو شکل پول کارتونی. متن دقیق درخواست‌ها در `docs/ART-PROMPTS.json` است.
- فایل‌های بهینهٔ WebP و فونت محلی در `public` قرار دارند.
- فونت Vazir 30.1.0 اثر صابر راستی‌کردار، با مجوز SIL OFL 1.1؛ مجوز در `docs/VAZIR-LICENSE.txt` محفوظ است.
- چرتکه با مهرهٔ پنج‌تایی و چهار مهرهٔ یک‌تایی در هر ستون کار می‌کند؛ کلیک یا حرکت لمسی مهره‌ها پشتیبانی می‌شود و عدد چرتکه مستقل از مبالغ فاکتور است.
- خروجی رسید روی Canvas با عرض ۱۰۸۰ پیکسل ساخته می‌شود. در iOS تصویر برای ذخیره با لمس طولانی نمایش داده می‌شود.

## ساختار

`src/model.ts`: مدل داده، اعتبارسنجی، بازیابی حساب و تقسیم صحیح تومان.
`src/App.tsx`: مراحل و فرم‌های حساب.
`src/receipt.ts`: تصویر مستقل رسید.
`src/Abacus.tsx`: چرتکهٔ تعاملی.

احترام به تنظیم کاهش حرکت، استفاده با صفحه‌کلید و مدیریت تمرکز دیالوگ حساب جدید در رابط لحاظ شده است.
